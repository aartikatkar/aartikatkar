# 🎓 Placement Cell Website

A web-based Placement Cell Management System designed to simplify the placement process for students, Training & Placement Officers (TPO), and recruiters. The platform enables students to register, apply for jobs, track applications, and receive placement updates, while companies can post job opportunities and manage recruitment efficiently.

---

## 📌 Features

### 👨‍🎓 Student
- Student Registration & Login
- Create and Update Profile
- Upload Resume
- View Company Job Openings
- Apply for Jobs
- Track Application Status
- View Placement Notifications

### 👨‍💼 Training & Placement Officer (Admin)
- Secure Admin Login
- Manage Student Records
- Approve Student Profiles
- Add/Edit/Delete Company Details
- Post Job Opportunities
- Schedule Placement Drives
- Generate Placement Reports

### 🏢 Recruiter
- Company Registration
- Post Job Vacancies
- View Eligible Students
- Download Student Resumes
- Shortlist Candidates

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/Placement-Cell-Website.git
```

2. Move the project to the XAMPP `htdocs` folder.

3. Start **Apache** and **MySQL** using XAMPP.

4. Import the SQL database into phpMyAdmin.

5. Open your browser and visit

```
http://localhost/Placement-Cell-Website
```
